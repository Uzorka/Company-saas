05 — Overlays

Drawers, dialogs, menus, toasts

Slide-over for reading a record without losing the list. Dialog only for a decision that blocks. Toast for anything already done.

Record
View profile
Edit attendance
Flag for review
Delete entry
Slide-over — 480px desktop, full-screen mobile. Enters from the right, 320ms. Scrim fades to 32% black. Esc and scrim click close; focus returns to the trigger row.
Dialog — max 460px, centred, 200ms scale-in from .97. Focus traps on the primary action; destructive dialogs put the safe action first.
Toast — bottom-right desktop, top mobile. 200ms rise, auto-dismiss 5s, pauses on hover, stacks to 3 then collapses to a counter.
Command palette — ⌘K anywhere. Scoped results: people, screens, actions. Arrow keys move, Enter runs, Esc closes.

Breakpoints & rules
< 640 — single column, bottom nav, sheets, sticky CTA, tables → cards.
640–1023 — two-column cards, sidebar collapses to icons, slide-over 80% width.
1024–1439 — full sidebar, real tables, slide-over 480px.
≥ 1440 — content caps at 1440, detail panels can dock beside the list.
Touch targets 44px minimum. Nothing important within 16px of a screen edge. Sheets never exceed 88% viewport height.
09 — Accessibility

Focus, contrast, keyboard

Focus specimen — tab through these
A 2px ring at 3:1 against both the control and the page, offset 2px. Focus is never removed, only restyled. Skip-to-content is the first tab stop on every page.
Keyboard map
⌘KCommand palette
/Focus list search
J / KMove through rows
EnterOpen record in slide-over
EscClose overlay, restore focus
Non-negotiables
Body text ≥ 4.5:1, headings ≥ 3:1, disabled text exempt but never the only cue.
Status = colour + glyph + word, always all three.
Every input has a persistent label; placeholders are examples, never labels.
Errors are announced via live region and tied to the field with aria-describedby.
Reduced motion drops transforms, keeps opacity, never removes feedback.
Phase 01 — decisions locked
IdentityHeron Blue #1B4F8C as the single brand hue; neutrals cool-grey; no gradients, no second brand colour.
TypeIBM Plex Sans UI + IBM Plex Mono for all figures, IDs, coordinates and timestamps.
ShellCollapsible role-filtered sidebar + topbar with breadcrumb, search, notifications, avatar. Org switcher present from day one.
RecordsSlide-over by default, dialog only for blocking decisions, full-screen on mobile.
MotionFive duration tokens, three easings, ceiling 420ms, full reduced-motion honour.
VerificationConsent-first copy, one-off capture, distance + accuracy always visible, every exception has a recovery path.
